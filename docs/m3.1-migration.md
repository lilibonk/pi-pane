# M3.1 候选迁移说明

本文对应本地候选 `@lilibonk/pi-pane@0.3.0-rc.3`，日期 2026-10-12。M3.1 是里程碑名；公开版本仍为 `0.2.0`。本轮不发布、不更新日常 pi 插件，最终候选测试结果待冻结后单独记录。[M3 的完成证据](m3-status.md)保留为历史，不改写为新候选的验收结论。

`/web` 仍先正常退出 TUI，再由前台宿主和一个 RPC 子进程提供网页工作台。关闭终端仍会停止服务；终端 Ctrl+C 停止后打印最新项目与已保存会话的恢复命令。没有新增后台常驻、实时 attach 或云中继。

## 界面入口与浏览器升级

左侧现在以“项目”和“会话”为主：项目旁的添加菜单提供“打开项目”“新建项目”，管理入口可从列表移除或重新定位目录。空会话把输入区居中；文件、改动和资源仍在工作台侧栏。移动端通过抽屉进入这些面板。

“设置”改为独立分类弹窗，包含“外观”“模型默认”“会话行为”“账户”“自定义供应商”“其他设置”。当前会话的模型仍在输入区旁选择，与全局模型默认分开。`/login`、`/logout` 打开账户，`/settings` 打开设置，`/session` 查看会话信息与用量，`/export` 导出 HTML，`/copy` 复制最后回复；这些内置命令不会作为普通模型消息发送。

浏览器协议升为 `pi-pane.v2`。已打开的 `0.2.0` 页面连接新版宿主时，认证成功后只收到明确的刷新提示并停止重试，不建立新租约、不接收宿主状态或会话快照；刷新以加载同包新版页面即可。提示不表示凭据被删除。刷新前请自行保留未发送草稿和图片，它们只在页面内存中。

## 项目记录、目录与空会话

项目是运行 pi 的电脑上的真实目录，手机上的目录选择器也操作这台主机。登记保存在 `<agentDir>/pi-pane/projects.json`，只记目录、名称、时间和最后保存会话，不复制项目文件。真实路径相同的符号链接别名归为同一项目。旧会话中的目录会纳入项目列表；从列表移除只隐藏登记，不删除目录、文件或历史会话，当前项目须先切走再移除。

“新建项目”只在选定父目录下创建一个新空目录，不克隆仓库、不运行脚手架、不自动 `git init`，已有同名目录不会被覆盖。目录创建成功后，即使后续会话启动或登记失败，该目录也保留；启动失败时按页面的恢复选择处理，需要时可重新打开或在主机上自行整理。

空项目可以没有历史会话。打开项目优先恢复它最后的已保存会话，否则让 pi 按自己的会话目录规则创建空会话，不由宿主伪造 JSONL。尚未落盘的空会话不能导出，也没有可以恢复的会话文件；首次有效消息由 pi 正常写盘。离开空会话后保留项目，未发送的草稿与图片按项目存放在当前页面内存里，刷新或关闭页面后丢失。

网页拒绝把 `.ssh`、`.gnupg`、`.aws`、`.azure`、`.pi`、`.codex` 内部，以及有效 agent、已知会话或 pi-pane 数据目录打开/创建为项目。确需在那里运行 pi，应在终端进入。打开 HOME 等上级目录时，文件预览和 Git 面板仍过滤这些真实路径，包括不使用默认名称的自定义 agent/session 目录；这不是模型工具的文件沙箱。

## 项目信任、环境与跨项目切换

项目需要信任选择时，可“信任并记住”“不加载项目配置，继续”或取消。信任会写入 pi 的项目记录，允许 pi 加载该项目的设置、资源与扩展，并按配置安装包；“不加载”仅影响本次打开。界面分开显示你的选择与实际观察到的项目命令，记住信任不保证所有项目资源已加载，全局扩展仍可能否决它。

项目不受信任也不等于工具被隔离：pi 工具仍能读写该目录，项目的 AGENTS 说明和其他普通上下文仍按 pi 规则读取。

不提供“仅本次信任”。pi 的 `--approve` 是进程级覆盖，可能跳过全局信任钩子，宿主不会替用户生成它；用户启动 pi 时已有的 `--approve` / `--no-approve` 只保留给起始项目，不带入其他项目。“不加载项目配置”会使用 `--no-approve`。

切到另一项目会先结束旧 RPC 子进程，再在目标目录启动一个新的子进程；工具的 cwd、项目资源和会话归属随之改变。原进程里未持久化的扩展内存不保留，没有每项目常驻进程。恢复已保存会话时按 pi 规则恢复模型，可用时保留原选择，不把最初启动的 `--model` 再盖上去；原模型或凭据失效时由 pi 选择回退并提示前后变化。相对 CLI 资源路径按起始目录固定，不在新目录中重新解释。

子进程环境来自启动 `/web` 的终端。切项目不会重新执行 shell 初始化、direnv、虚拟环境激活或读取另一个终端刚改的环境变量。需要不同环境时，应停止服务，在目标环境里重新启动 pi。

同项目原生会话切换与凭据/设置的进程内应用保留 pi 扩展的 veto；跨项目换进程无法等价提供原生 `session_before_switch` 的否决语义。它要求回复结束、队列为空、无待答对话框，并在停止前重新核对会话与锁。依赖这些切换钩子维护内存状态的扩展，应在终端切换项目。

关闭阶段的扩展如果再弹出问题，stdin 已关闭，网页无法回答；未能正常结束或需被强制终止时不启动目标项目。页面进入恢复状态，可明确重试、在安全条件下回到旧项目或停止服务，不自动循环重启。

关闭 stdin 到子进程退出的窗口内，宿主不能再用 `get_entries` 证明最后追加的归属。实现只按有界规则接受：原文件身份和已接受前缀不变、仅合法完整的非消息条目追加、子进程退出后文件不再变化；不会把此规则称作归属证明。消息条目、替换/截断或不完整末行会阻止激活目标，必要时停止服务。子进程全生命周期保留父进程 IPC 断开保护，涵盖启动和关闭钩子等待窗口。

## 账户作用域与应用

“设置 → 账户”使用 pi 的公开认证接口提供支持的 API key 登录。凭据写入有效 `<agentDir>/auth.json`，供使用同一 agent 目录的所有项目使用；它不是每项目密钥，也不是 pi-pane 自建账户库。新输入按字面值处理，不把开头的 `!` 或 `$` 当作命令/环境引用，秘密不放进普通操作回执或广播给其他页面。

OAuth 网页入口继续禁用：设备码流程虽有适配，但尚未完成真实账户验证；需要本机回调的流程尚未实现。页面说明原因并指向终端 `/login`，已有 OAuth 凭据照常交给 pi 使用。IAM/ADC、环境变量和启动参数等凭据来源不在网页登录表单的管理范围内。

一次只有一个账户交互。具体步骤只发给发起页，其他页面可以继续对话并可取消该操作，不能查看或回答密钥步骤。短暂断线不立即取消，发起页在租约仍有效时可刷新/重连继续；未提交的密钥输入不保留。操作可由用户取消，也会在 15 分钟上限、发起页租约失效或服务停止时结束。

“凭据已保存”和“当前会话已应用”是两个结果。当前宿主空闲时尝试通过 pi 的原生会话重载应用；正在回复、有排队消息或待答对话框时保持“待应用”，结束后点“立即应用”。扩展否决时原运行时继续可用，保存结果保留，可稍后重试。这只应用到当前 `/web` 宿主，不自动让其他 pi 终端或另一个宿主重载。

注销只删除 pi 保存的那份凭据，不撤销供应商端的授权/密钥，也不能移除环境变量、CLI 或 `models.json` 中的其他来源。注销后仍可能有可用凭据；页面以实际配置来源与运行时结果说明状态。

## 自定义供应商

“设置 → 自定义供应商”可接入 pi 已支持 API 协议的服务，编辑名称、协议、Base URL、模型 ID/显示名/上下文长度，配置保存到全局 `<agentDir>/models.json`。保存后通过“设置密钥”走 pi 登录，把密钥存到 `auth.json`，不向供应商表单或新建的 `models.json` 条目写入密钥。

已有 `models.json` 密钥只显示来源类别，不显示、执行或改写内容。请求头、输入类型、采样参数、`modelOverrides` 及未知字段等表单外配置只读保留，仍须在主机文件里编辑；主动删除某个模型会同时移除该模型附带的配置。内置或扩展供应商名称不能用来新增；已有内置覆盖条目保留只读说明。损坏文件和过期页面提交会拒绝写入，不静默重置文件。

保存配置不探测远端地址，“已配置，未验证”不能视为服务可用；应用后会显示当前运行时实际列出的模型。明文非回环 HTTP 地址可以保存，但页面会警告。保存与删除同样遵循当前宿主的待应用流程。

删除前显示受影响模型数及是否为当前模型；删除会移除该供应商配置，并尝试清除 pi 为它保存的凭据，结果分别说明。应用后由 pi 决定当前模型，页面提示前后变化或需要重新选择模型；不另加发送拦截，也不声称撤销了所有凭据来源。

## 外观、pi 默认与覆盖

“设置 → 外观”的浏览器外观支持跟随 pi、跟随设备、浅色、深色和已安装的 pi 主题。预览后保存才保留，关闭设置取消未保存预览。它只写此浏览器的 `localStorage`，不改终端主题；协议、主机或端口改变就是另一个 origin，偏好不会自动跟过去。多设备分别选择。

重做的默认主题为 `pi-pane-light`、`pi-pane-dark`，新增浅色 `pi-pane-porcelain` 青花瓷主题。青花瓷纹样只绑定本包的真实主题来源，第三方同名主题不会获得纹样，也不能让网页加载任意图片/CSS/URL。“显示主题装饰”可关闭纹样，高对比度或强制颜色模式自动隐藏；装饰仅在网页留白显示，TUI 只加载配色。安装包包含主题；仅用 `pi -e .` 加载扩展不会把它们安装为后续 TUI 可发现的包主题。

“保存为 pi 默认”是独立操作，写入 `<agentDir>/settings.json` 的全局值。网页展示全局默认、项目覆盖、启动参数和当前会话值；不会写项目设置。以主题为例，`--use-theme` 高于受信任项目配置，项目配置高于全局默认。pi 的 `system` 是终端配色快照，网页“跟随设备”则使用浏览器系统外观，两者不同。

默认模型/思考强度用于后续会话，不改当前会话；当前模型仍通过输入区旁的选择器修改。引导/后续消息模式、自动压缩与重试由 pi RPC 修改并保存全局默认；图片发送开关等需重载的设置使用待应用流程。保存逐项校验，未知配置保留；文件损坏时只读，项目覆盖仍生效时明确显示“全局已保存，但在当前项目不生效”。

## 会话删除、导出与复制

删除只接受网页列表已暴露的、非当前且未被其他 `/web` 宿主持锁的已保存会话。确认框显示名称、项目和主机路径；执行时重新检查会话文件和 ID，并持有该文件的锁。优先使用 `trash` 移入废纸篓，不可用或未成功移除时回退到永久删除，完成提示明确说明实际方式。普通 pi TUI 不遵守该锁，网页不能知道它是否也正打开此会话；删除前请自行确认。删除后项目的最后会话引用会清理。

HTML 导出由 pi 写入 `<agentDir>/pi-pane/exports`，浏览器不能任意指定输出路径，宿主保留最近 20 份。文件不超过 32 MiB 时可在浏览器下载，超出只显示主机路径。导出包含会话内容，可能有工具读取的文件、私人信息与密钥，分享前需检查；当前未提供 JSONL 导出、导入或公开分享链接。

助手消息复制和 `/copy` 只复制回复文字，不含思考或工具调用；剪贴板权限被拒时显示可选中文本，不误报成功。`/session` 与输入区用量来自 pi 会话统计，费用是 pi 报告的会话估算，不是账户余额或套餐额度查询。

## 兼容性与剩余边界

会话 JSONL、`auth.json`、`settings.json` 和 `models.json` 继续使用 pi 原生格式；项目注册表与 HTML 导出是额外文件，`0.2.0` 可忽略。候选不批量改写原历史。回退旧插件时需停止当前宿主并加载与旧宿主配套的网页；若全局默认选了旧包不带的青花瓷主题，应先改回仍可发现的主题。回退插件不会自动撤销你明确保存的配置、凭据或删除操作。

常用模型范围（`/scoped-models`）、资源包安装/启停、MCP 管理仍须在终端完成。工具列表/启停、tree 导航、任意 custom TUI、Plan/Goal/Agent 执行语义尚未补齐；`/share`、`/import`、`/bug` 等保持终端入口。`/web` 仍要求已保存且空闲的交互 TUI 会话，Windows、`--no-session`、后台常驻和关闭终端后继续运行不在当前支持范围。

本说明逐项覆盖[计划第 12 节](m3.1-plan.md#12-版本发布与迁移)；认证支持范围、实现边界与最终冻结候选证据分别记录，不以文档或本地打包代替里程碑验收。

## 本候选的审核边界

本候选保留已知审核发现，详见[M3.1 状态](m3.1-status.md)：IPC 断开清理不是所有扩展命令的无孤儿保证；删除保护根而保留可解析父目录的历史 diff 反例已修正，但上级链接删除/悬空、保护路径权限错误、缺失目录大小写变体及请求内链接改指仍有已复现边界。移除唯一可用模型的供应商时，真实页面会提示没有可用模型，现有网页禁用发送并保留草稿；可用列表刷新失败时仍存在提示误报，初次交接或断线期间的广播提示也可能丢失。这些发现没有通过修改产品或放宽验证断言来消除，候选冻结不代表发布验收通过。
